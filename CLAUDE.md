# CLAUDE.md

This repository is `@nostr-git/core` — a single npm package bridging Git and Nostr.

**Agents:** read **[AGENTS.md](AGENTS.md)** first. It is the authoritative
orientation: repository layout, hard rules (tag helpers, the `EventIO`
abstraction, provider policy), event kinds, error model, worker model,
conventions, and build/test commands.

Additional references:
- Architecture: [ARCHITECTURE.md](ARCHITECTURE.md)
- Public API: [API.md](API.md)
- Development: [DEVELOPMENT.md](DEVELOPMENT.md)

> Note: docs mentioning `@nostr-git/ui`, `@nostr-git/shared-types`, or
> `@nostr-git/git-wrapper` describe a former monorepo; this repo is now a
> single package.
